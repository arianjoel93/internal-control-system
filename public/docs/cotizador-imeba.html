Documentación del Cotizador IMEBA

Guía para usar el cotizador de etiquetas digitales basado en la lógica del Excel IMEBA, entender cada campo y revisar la cotización antes de presentarla al cliente.

ObjetivoFlujoCamposCriteriosResultadosEjemplosValidación

1. Objetivo

El Cotizador IMEBA calcula precios de etiquetas considerando tipo de cambio, margen, material, tinta, medidas, cantidad, millares y condiciones de producción. Su propósito es estandarizar criterios para que el precio sea consistente y comparable con el Excel original.

No reemplaza la revisión técnica de producción. Si hay acabados especiales, urgencia, tolerancias, pruebas de color, materiales fuera de catálogo o condiciones comerciales especiales, se debe validar antes de enviar la propuesta final.

2. Flujo recomendado

1. Captura datos base

Tipo de cambio, margen, material, tinta y medidas de etiqueta.

2. Define cantidad

Indica millares o cantidad equivalente. Revisa pedido mínimo.

3. Valida producción

Si hay etiquetado automático, activa orientación y revisa criterios aplicados.

4. Revisa resultados

Confirma precio unitario, precio por millar, total y criterios finales.

El módulo sigue la lógica del Excel IMEBA y muestra resultados con tres decimales para aproximar los cálculos del archivo original.

Las fórmulas exactas se mantienen dentro del cotizador para replicar el comportamiento del Excel. Esta documentación explica cómo interpretar cada bloque.

6. Ejemplos prácticos

Ejemplo 1: etiqueta sencilla

Una etiqueta pequeña con tinta baja y material estándar debe generar un costo controlado. Si el precio final se ve alto, revisa margen, millares y pedido mínimo.

Ejemplo 2: tinta alta

Un diseño con fondo completo, colores sólidos o mucha cobertura debe usarse como tinta alta. Si se cotiza como tinta baja, la utilidad puede quedar subestimada.

Ejemplo 3: etiquetado automático

Si el cliente aplicará etiquetas con máquina, la orientación deja de ser solo visual. Debe validarse sentido de salida, rollo y aplicación antes de confirmar.
